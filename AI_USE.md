# AI use

This project was implemented with an AI assistant using Copilot SDK in VS Code, following the provided engineering-assessment brief. The assistant helped inspect and modify the existing code, add project configuration and documentation, and create tests.

The application's audio generator does not use generative AI: it is a local, rule-based DSP synthesizer written with NumPy and SciPy. No paid AI service, model API, or external media was used or required.
